Empieza por un proyecto

Un proyecto agrupa el código de un sistema legacy y todo lo que LegacyLift aprende de él. Así es el recorrido:

  1. EntenderImporta el código y obtén inventario, arquitectura y riesgos.
  2. PlanificarAprueba un plan por waves y registra el comportamiento actual.
  3. ModernizarRevisa el candidato generado sobre una copia y decide si lo aceptas.
  4. EntregarDescarga el código modernizado con su evidencia.
