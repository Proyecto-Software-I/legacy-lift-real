Motor de análisis Las credenciales viven en el backend, nunca en el navegador.

Cada paso produce evidencia que usa el siguiente. El código original nunca se modifica y cada cambio pasa por tu aprobación.

  1. Entender. Importa un ZIP o un repositorio. Discover, Understand y Assess describen el sistema y sus riesgos.
  2. Planificar. Plan propone waves de cambio; apruebas el Blueprint y una wave. Baseline registra el comportamiento actual.
  3. Modernizar. Modernize genera un candidato sobre una copia. Verify lo compara con el original y tú decides.
  4. Entregar. Descarga el código modernizado, el parche y el informe.

Para comparar pruebas reales el servidor necesita VALIDATION_MODE=docker. En modo estático solo se comprueba la sintaxis y no se declara equivalencia.
