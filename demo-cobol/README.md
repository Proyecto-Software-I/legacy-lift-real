# Sistema Bancario de Nómina e Intereses en COBOL (Demo LegacyLift)

Repositorio COBOL de ejemplo para pruebas de análisis, planificación y modernización segura (`safe-refactor@1.0`).

## Estructura

- `src/PAYROLL.cbl`: Programa principal de liquidación de nómina, bonificaciones y retenciones.
- `src/INTEREST.cbl`: Subprograma de cálculo de intereses y amortización de cuentas.
- `copybooks/ACCOUNT.cpy`: Estructura de registro de cuenta y empleado (Copybook).
